# Лимиты действий за ход — решение владельца 16.10.2026

Задача: [#227](https://github.com/MythHand/ReleaseBoardGameP2P/issues/227).
Владелец повторно подтвердил оба дефекта и согласовал следующие границы перед исправлением.

## Добор

Один обычный добор за ход. В Base он берёт по карте с каждой актуальной на начало действия
колоды; в Strategic — одну с выбранной. Git Branch и Git Merge после завершения действия
не разрешают добирать снова. Прерывание триггером продолжает ту же последовательность;
дополнительные доборы, явно заданные эффектом карты, сохраняются.

## Успешный релиз

Лимит Base — один успешный релиз с руки за ход. Успех: релиз пережил окно атак и остался
у выпустившего игрока. С Code Review успех наступает сразу. Если релиз уничтожен или украден
в этом окне, можно повторить попытку после окончания обмена. Позднейшая потеря уже успешного
релиза лимит не возвращает. Fast Release остаётся без ограничения; AI-релизы и карты,
полученные кражей, не расходуют лимит релиза с руки.

Это уточнение заменяет прежнее «можно выложить только одну карту Release» в тексте правил.
Стоимость и последовательность разрешения атак не меняются.
