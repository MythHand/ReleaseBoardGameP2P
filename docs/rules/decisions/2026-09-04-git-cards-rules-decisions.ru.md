## Git Rebase

**1. Колоду называет игрок.** Rebase без sudo говорит о «трёх верхних картах **одной** колоды
добора», а после Git Branch колод несколько. Игрок выбирает, какую, — так же, как выбирает колоду для
разделения (ответ 3 в [записи частей 1–2](./2026-08-01-git-operations-open-questions.ru.md)).

Поэтому розыгрыш Rebase несёт цель «колода» — тот же вариант, что уже добавил Git Branch, а не
второй, придуманный заново. Sudo это не касается: он достаёт до всех колод и потому ни одну не
называет.

**В игре.** Так: при нескольких колодах колоды подсвечиваются, и розыгрыш ждёт клика по одной; при
одной колоде карта играется сразу; с sudo показываются все колоды, и ни одну не называют.
**В спеке.** [`cards.md`, Git Rebase](../cards.md#git-rebase--operation-git-rebase--тираж-3--sudo).

**2. Короткая колода переставляется как есть; без колод карта сыграна впустую.** Две карты можно
поменять местами, одна — законный ход, который ничего не меняет, а когда колод добора не осталось
вовсе, эффект пропускается, но карта считается сыгранной.

Это та же форма, которую владелец уже выбрал дважды: ответ 4 делает Git Branch на колоде из одной
карты законным розыгрышем, который ничего не делает, а ответ 11 делает невозможное взятие из сброса
«законным ходом с последствиями для игрока, который затупил, — а не отклонённым действием».
Расточительный розыгрыш — ошибка самого игрока, и движок его от неё не защищает.

**В игре.** Так. Пустые колоды из выбора выпадают; когда колод нет совсем, карта тратится, и выбор не
открывается. Если в колоде одна карта, выбор всё равно открывается и показывает эту одну карту:
переставлять нечего, порядок остаётся прежним.
**В спеке.** [`cards.md`, Git Rebase](../cards.md#git-rebase--operation-git-rebase--тираж-3--sudo).

## System Upgrade

**3. Сопернику с пустой рукой сбрасывать нечего.** Его не спрашивают вовсе: эффект не вносит его в
список, поэтому не может зависнуть в ожидании карты, которой у него нет. Остальные соперники
сбрасывают как обычно. Если сбросить не может никто, карта сыграна, в центр ничего не попадает, и
sudo ничего не берёт — брать нечего.

Рассматривался и отвергнут вариант, при котором игрок с пустой рукой добирает карту, чтобы её
сбросить. Тогда System Upgrade стала бы единственной операцией, которая двигает колоду добора как
побочный эффект.

**В игре.** Так: сбросить должны все, кроме сыгравшего, выбывших и тех, у кого пустая рука; если
должников нет, карта сыграна, в центр ничего не попадает, и sudo брать нечего.
**В спеке.** [`cards.md`, System Upgrade](../cards.md#system-upgrade--operation-system-upgrade--тираж-2--sudo).
**Онлайн.** Соперники сбрасывают одновременно, каждый сам за себя, лицом вверх в центр стола.

## Что эти ответы меняют

1. **У Rebase появляется цель**, и он несёт её в том же варианте «колода», что у Git Branch. Новой
   формы действия нет.
2. **У Rebase нет незаконного случая, который стоило бы отклонять.** Любое состояние колод — законный
   розыгрыш; разница только в том, сколько эффекта случается. Движку не нужно отклонение «мало карт»,
   а доске — неактивное состояние карты.
3. **Список тех, кто сбрасывает при System Upgrade, вычисляется, а не предполагается.** Кто должен
   сбросить, решается в момент, когда эффект открывается: все, кроме сыгравшего, минус выбывшие, минус
   те, у кого пустая рука. Пустой список — обычный исход, а не ошибка.
