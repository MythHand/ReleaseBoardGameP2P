# Name and logos

Release любой ценой™ is the name of this game; MythHand™ is the name Dmitry Togulev releases his
projects under. The names and the MythHand logo belong to Dmitry Togulev, the Release любой ценой
logo to Dmitry Togulev and Alexey Shtyrnyaev. Release любой ценой has been used publicly since
2025, MythHand since 2026. The official
home of the game is [mythhand.space/release/about](https://mythhand.space/release/about). This
page sets out how the name and the logos may and may not be used. The logo files themselves are

[`LICENSES/LicenseRef-AllRightsReserved.txt`](./LICENSES/LicenseRef-AllRightsReserved.txt).

## What counts as a modified version

Any change to the project other than setting up the environment it runs in makes a copy
modified: a change to the code — the logic, the behaviour, the interface — or to the rules, the
cards, the texts, the logos or the sounds, however small, and whether a player would notice it
or not.

Setting up the environment is what the project leaves to be set outside its code: the values in
its `.env` files — the signalling server, the TURN relay and their credentials — the ports, the
address and path the game is served from, and how it is built and deployed. None of this changes
what the game is.

## Fine

- Referring to the project by its name — in an article, a review, a video or a link, or to say
  that your work is a fork of it or is compatible with it.
- Running a copy for yourself, changed or not, where no one else can reach it — to try the
  project, or to prepare a change to it.
- Running or redistributing an unmodified copy of this project non-commercially, with its name
  and logos as they are.
- Running an unmodified copy inside a company or another organisation for its own staff,
  team-building included.
- A mod, on the terms below.

## Mods

A modified version run or shared publicly and non-commercially may keep the name and the logos
as a reference to the original, on these terms:

- **It has a name of its own, and that name comes first.** The browser tab title starts with
  the mod's name; ours may follow it only as a reference to the original. Fine:
  "Deadline Edited · Release любой ценой", "Deadline Edited — мод Release любой ценой",
  "Deadline Edited по Release любой ценой". Not fine: "Release любой ценой",
  "Release любой ценой 2", "Release любой ценой: Deadline Edited" — each of these reads as the
  original or as a part of it.
- **Every screen a player enters by says it is a mod.** The Start screen (`/start`), the Invite
  screen (the one an invite link opens) and the Lobby screen each carry a clear mark, in the
  mod's own words: a player who sees only that screen must understand that it is not the
  original game, and that it is based on Release любой ценой. On the Start and Invite screens
  the mark stands next to the logo.
- **The settings drawer on the Table screen — the game itself — carries this notice word for
  word**, in the language the game is shown in, with the mod's name and author filled in:

  > «Mod name» by Author's name — an unofficial modified version of Release любой ценой. Not
  > affiliated with or endorsed by the game's authors. The original:
  > https://mythhand.space/release/about

  > «Название мода», автор: Имя автора — неофициальная изменённая версия Release любой ценой.
  > Не связана с авторами игры и не одобрена ими. Оригинал: https://mythhand.space/release/about

- **The logo files stay as they are** — not recoloured, redrawn, or combined with another mark.
- **Non-commercial only.** A modified version played inside a company or another organisation —
  at work, team-building included — is not a mod but commercial use.
- **The permission can be withdrawn** for a particular mod — for instance, if it harms the
  game's name. That mod then takes our name and logos out.

## Not fine

- Using the name or the logos as the name or branding of your own version, product or service.
  A mod uses ours only as a reference, as set out above; any other modified version takes a name
  and logos of its own.
- Presenting your copy — modified or not — as the official Release любой ценой, or implying
  that its authors run or endorse it.
- Using the name or the logos commercially, on merchandise, or in any other project.

To ask about anything not covered here, open an issue in this repository.
